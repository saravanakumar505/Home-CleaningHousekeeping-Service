1. Technology Stack & Philosophy

PureNest is built purely with standard web technologies: HTML5, TailwindCSS, Vanilla JavaScript, and Lucide SVG Icons. There is zero runtime compilation, no Webpack/Vite complexity, and zero dependency on jQuery, Bootstrap, React, or Vue.

2. CSS Design Tokens & Variables

All brand colors are parameterized in assets/css/style.css: 

:root {
  --primary: #2E8B72;       /* Teal / Emerald */
  --primary-dark: #1E6B56;
  --primary-light: #E8F5F0;
  --secondary: #F2B866;     /* Warm Gold / Sand */
  --background: #F7F8F5;    /* Warm Clean White */
  --surface: #FFFFFF;
  --text-main: #18211F;
  --text-muted: #5E6D69;
  --border: #DDE5E1;
}
